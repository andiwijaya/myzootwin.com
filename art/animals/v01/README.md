# Original animal asset workshop

Started 15 November 2026. This is new editable MyZooTwin artwork, not an export of the old faceted runtime geometry. Sources describe continuous implicit anatomical volumes, smooth blended skinning, surface coat functions, and separately articulated details. The build retains self-contained high/low GLB masters, embedded original texture atlases, skeletons and sampled clips. Runtime delivery is generated separately.

The existing simulation's stable residents and contact/pose contracts are retained. Authoring coordinates are sanctuary scene coordinates; one scene unit is not asserted to equal a biological metre. Per-species real-world dimensions and visual calibration are recorded in `references.json`. Scientific identity remains the one already present in the game, including `Giraffa sp.`. Individual coat designs are original interpretations, not photo-identification records of real animals.

No external mesh, photograph pixels, font, downloaded texture or new public licence is included. Zoological references supply anatomical facts only. Existing Pelatuk assets remain under their original provenance and are never relabelled as new animal artwork.

Build with `node art/animals/v01/build.mjs`. Keep rejected iterations and their QA receipts. Generated geometry is not accepted visually until the retained GLB has been reopened and reviewed in the current MyZooTwin harness.
