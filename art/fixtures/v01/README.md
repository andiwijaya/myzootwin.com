# MyZooTwin fixture GLBs v01

Editable original authoring is `build.mjs`. Run with the installed Node/Three environment; no browser download is used. The retained GLBs and the Brotli web derivatives are written locally. Coordinates preserve the existing simulation world and paid resource IDs. The mesh roots are ground anchored; the renderer places ports from each real resource's `approaches` and uses named stock nodes. The GLB root extras record provenance and the authoring contract.

The 22 templates cover the existing macaw, elephant, lion, giraffe and zebra care facilities. Their small static meshes share one geometry detail across high/low; the animals and Pelatuk foliage have separate high/low models. Water, food portions and leaves remain GLB nodes whose transforms/visibility read actual saved stock and simulation time. Footprints, simulation routes, purchases and benefits stay owned by the simulation.
