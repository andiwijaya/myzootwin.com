# Four-habitat homepage refresh

The homepage now introduces the existing four-habitat game: Macaw Aviary, Elephant Grove, Lion Savanna and Giraffe Plains. Indonesian is served at `/`; English is served at `/en/`. Both are complete static pages, including navigation, privacy UI, titles, descriptions, canonical URLs, language alternates and social metadata. Language links work without JavaScript. All play links use the existing `/play/` entry; habitat unlocks are described as progression rather than instant access.

Production was audited before implementation. Cloudflare project `myzootwin-com` confirmed `andiwijaya/myzootwin.com`, production branch `main`, automatic deployments enabled, source `1097ed319f60a5b4155f03210ae3c947d6c37d06`, successful deployment `41b21aca-95af-4ce3-9ec5-b196484d4837`, and the apex/www domain aliases. The deployed PlayEntry and foundation-scene bundles match the candidate byte for byte. Gameplay, engine, persistence, package manifest and lockfile are unchanged.

The hero and Giraffe spotlight use real source-bound gameplay screenshots already preserved in `docs/qa/giraffe-native-final/`. Only canvas cropping, resizing and encoding were applied; the social image contains the full original screenshot. Responsive WebP files are 18–31 KB; the 1200×630 social JPEG is 86 KB. Original captures and useful existing media are preserved. See [image provenance](qa/homepage-refresh/image-provenance.json).

The page has one H1, semantic H2 sections, descriptive alternatives, a native keyboard-accessible FAQ and links to the animal journal/About. VideoGame structured data states factual platform, genre and languages, with no ratings or mission counts. The homepage imports only the existing site/privacy module, without the game engine. The standard QA route checks now include `/en/` and preserve the other released route metadata checks.

Local evidence: [static audit](qa/homepage-refresh/static-audit.json), [HTTP route/asset equality](qa/homepage-refresh/http-local.json), [internal-browser observations](qa/homepage-refresh/browser-local.json), [unchanged production game bundles](qa/homepage-refresh/game-baseline.json), [Astro diagnostics](qa/homepage-refresh/check-final.log) and [isolated build](qa/homepage-refresh/build-final.log). Browser coverage includes ID/EN at 1366×768, 360×780 and 780×360; CTA Enter, Back/Forward, language links, in-page anchor, FAQ Space, privacy Escape/focus return and skip-link focus. No physical device or fresh full-game soak is claimed. The apex owner's detected save was never continued, reset or exported. All browser QA used the internal browser.

Dependency synchronization added only the already-locked `fake-indexeddb` QA package to the old local installation; package.json and package-lock.json stayed unchanged. Build output was isolated from the owner's `dist`. The existing large game-chunk warning remains; those chunks are not eagerly loaded by the homepage. An initial inaccessible sandbox preview and a rebuild-directory permission error were resolved with an owned loopback server and a fresh isolated output, without touching other project processes.

Final test summary and live deployment evidence are recorded in the release receipt after their actual completion. No Cloudflare configuration or domain change is part of this release.
