## Player behavior

Settings offers Auto/Low/High graphics, reduced decorative motion and mute in ID/EN. Visual/sound edits require Apply; Close or Escape discards unapplied drafts. Language remains immediate. Settings waits for storage/control readiness; Help remains available while loading. Current manual device choices take priority over a saved game's preferences, with valid save/default fallback. Defaults are Auto, normal decorative motion (system reduced-motion preference still wins), and muted. Storage errors use truthful temporary-preference and game-save messages.

Low mode caps pixel ratio at 1, removes contact shade/water glints, simplifies vegetation lighting and displays at most one guest model. Every animal/guest/economic/mission state still simulates. High restores effects and visible models; Auto uses a narrow viewport or coarse-pointer preference. Essential animal movement remains; Pause stops the world. Existing materials are reused rather than allocated on quality toggles.

The optional ambience is original deterministic eight-second mono creek/noise and stylized chirps, generated by code, not a macaw-call recording. No downloaded samples, microphone, camera, external service, new permission or new dependency. [Provenance](../art/audio-v1/README.md). Audio defaults off, needs an actual trusted game action after unmute, and never starts from hydration alone. One AudioContext owns a looping buffer source, gain and analyser independently of simulation/render speed. Pause/dialog/background holds silence/suspend it; closing/disposal releases all nodes/context. Failure leaves gameplay usable and provides bilingual retry/mute feedback.

Preference changes touch no money, world, mission or simulation time. Only the existing serializable muted/graphics/reducedMotion fields and small versioned device preferences persist; no AudioContext/DOM/mesh references enter saves. Reset preserves preferences and retains the recoverable original-game backup through the existing reset contract.
