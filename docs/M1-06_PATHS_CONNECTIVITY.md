Invalid/paused/disposed/cancelled/stale/duplicate actions cannot create extra path cells. Preview confirmation also revalidates current world/revision. No renderer position/animation completion decides accessibility.

`world/paths.ts` performs BFS from the actual gate using traversable, unoccupied land-path cells and four orthogonal neighbors. Diagonal touching, proximity and an isolated path beside the habitat grant no access. For each habitat it selects the reachable adjacent exterior path with shortest gate distance, deterministic tie breaking and an ordered gate→viewing route. The real habitat `viewingCell` becomes that tile or null. A constructor recomputes this cache from topology rather than trusting stale saved access. Serializable saves retain path flags/viewingCell; the graph is derived runtime data, cloned on read. This is a route contract for later visitor walking, not a visitor implementation or completed Q01 mission.
