# Z4-02 causal Zebra welfare

Candidate under verification; this file alone is not acceptance evidence.

The score is a fictional game approximation. Six live components contribute to a rounded 0–100 score: nutrition 25%, hydration 25%, rest 20%, movement space 10%, social comfort 10%, enrichment 10%. The ID/EN care panel explicitly says it is not veterinary guidance and exposes each component with its cause/remedy in a keyboard-operable disclosure per resident.

Nutrition/hydration use actual hunger/thirst relief. A reachable stocked facility permits the full remaining need value; an empty reachable facility caps it at 80; missing/unreachable facilities cap it at 40. This preserves the benefit of finishing a last portion. Refilling never directly changes hunger, thirst, energy, comfort or completed counters. Rest combines energy and shade comfort when shade is reachable; without shade it uses 35% of energy. Space counts the original legal 169-node ground grid, not new land or altered world dimensions. Social comfort is capped at 50 for an adult without companions. Enrichment uses only earned enrichment comfort; it is optional and independently weighted.

Availability uses the original static route graph and service ports, ignoring temporary actor reservations. Static components are cached by the actual world object and habitat/prop geometry signature; stock and animal needs are always read live. Component connectivity is equivalent to the original direct-segment/four-neighbour BFS existence test. Placement changes invalidate geometry, while refills require no graph reconstruction. No additional clock, random draw, cosmetic credit or permanent path engine is introduced.

Reading a panel and loading a paused historical V5 payload preserve its bytes. A real canonical tick or accepted Zebra welcome/build/refill command derives persisted Zebra welfare, habitat fit and care flags. Prepare creates the exact validated candidate; adoption recomputes it and checks equality, retaining existing CAS boundaries. Old species' welfare rules and fields are not changed.

Audit also found an optional-enrichment dependency defect: grooming and herd episodes required enrichment >=35, but unrefilled welcome enrichment decayed below35 before basic care could finish. These optional episodes now depend on adequate food, water, energy and shade; enrichment continues to decay and affect its own welfare component. Genuine reciprocal contact is still required for social relief. An actual source-command fixture without any enrichment facility must demonstrate completed grooming at zero enrichment.

Native performance, the full five-species matrix, proposed grant affordability and public V5 adoption remain separate open gates. Source playback is not native elapsed time or presented FPS. No Zebra push/deploy is authorized.
