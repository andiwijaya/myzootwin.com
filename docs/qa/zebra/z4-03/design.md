The existing shared economy already charges two fictional ZC per habitat per600 canonical ticks. Five habitats therefore cost10ZC per period. Unaffordable maintenance remains due rather than overdrawing the wallet. Original gate admission produces one10ZC receipt for a visitor, independently of the number of habitats. These rules are reused unchanged and covered by five-habitat source tests, including actual paid Zebra admission, cold1x10x, compaction and repeated admission checks. The cashflow panel now separately displays an existing Zebra grant receipt, conditional on its presence; this is accounting, not a new grant command or budget acceptance.

Zebra care facilities gain explicit remove/review/cancel and Undo controls with ID/EN stock/refund terms. Removal refunds only outstanding actual construction debits. Refill fees are never refunded, and remaining stock leaves with the facility. Undo repays the exact refund and restores that removed facility with its frozen remaining stock. Other facilities keep their current stocks and revisions; neither animals nor committed routes are rewound. Undo remains a page-session memento across renderer replacement, and ends after a new purchase/edit or page reload. This limitation is disclosed in the product review.

A pure Zebra edit candidate uses the original shared purchase/refund book, bounded command IDs, strictV5 parser, financial compaction and existing geometry guards. It does not instantiate a second engine/clock. Actual product actions freeze the canonical owner while the existing durable backend performs CAS. Only an exact accepted candidate changes live world/money/editor state. Refused, stale, forged, conflicting, quota-failed or late disposed candidates cannot publish optimistic refunds. The generic product Undo control routes Zebra mementos through the same durable path; old-species edit behavior remains unchanged.

Facilities with an actual approaching/using Zebra cannot be removed. Restore checks live roots, targets, every remaining route segment, the original swept body and grooming-head guards. It refuses occupied space instead of relocating a resident. A Zebra memento must describe exactly one removed Zebra prop, and refund references must trace to that prop’s original build receipts. Stock revision normalization is limited to Zebra consumption when comparing otherwise identical world structure.
